# cao-xt — CAO-XTensions (Archiv)

Dieses Repository enthält die alten **CAO-XTensions** — eine webbasierte Erweiterung
für CAO-Faktura (PHP), ursprünglich von Daniel Marcus (Black Heartware OHG),
letzte bekannte Anpassung von Wolfgang Schwarz (2007), Quelle: http://www.imc-media.com

Hinweis: „xt" steht für eXTension (nicht xt-commerce). Mit aktuellen CAO-Faktura-Versionen
sind die Module nicht mehr ohne Weiteres verwendbar — sie werden hier nur **archiviert**.

Der Code liegt unter [`caoxt/`](caoxt/).

## Dorfkern ausgelagert
Unsere eigene Dorfladen-Erweiterung **„Dorfkern"** (Python/Flask-Suite: Kasse, Kiosk, Orga,
Admin, DATEV-Export, Backwaren-Erfassung, Vorbestellungen, Mittagstisch u. a.) wurde in ein
eigenes, **privates** Repository verschoben.
