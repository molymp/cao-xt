⬆️ System-Updates

Vergleicht den lokalen Stand mit origin/<branch>. Wenn neue Commits vorliegen, kann das Update direkt von hier aus gestartet werden: Apps werden gestoppt, git pull ausgeführt, Apps wieder hochgefahren. DB-Migrationen laufen beim Admin-Start automatisch.

Neue Commits
    ✓ Das System ist aktuell.
    🔄 Neustart erforderlich.
    Alle Apps werden in Reihenfolge neu gestartet. Die Admin-Verbindung bricht für ca. 5 Sekunden ab; die Seite lädt sich automatisch neu. (Nur Admin neu zu starten würde die anderen Apps mit altem Code weiterlaufen lassen.)

    Alle Apps werden kurz gestoppt und neu gestartet. Fortschritt erscheint unten.

    Konsolen-Fallback

    Falls die Admin-App selbst defekt ist, kann das Update direkt über das Installationsscript gestartet werden:

    ./install.sh --update

    Das Script schreibt den Fortschritt nach /tmp/<prefix>-update.log (per Default /tmp/dorfkern-update.log; bei Multi-Instanz mit Suffix, z. B. /tmp/dorfkern-prod-update.log).
