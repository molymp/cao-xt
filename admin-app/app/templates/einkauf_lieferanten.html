📬 Gmail-API

Workspace-Konten brauchen seit 2025 OAuth statt Klartext-Passwort. Einmaliges Setup in der Google-Cloud-Console, danach laeuft das Postfach im Hintergrund.

📖 Erst-Einrichtung in der Cloud Console (1× pro Postfach)
  1. console.cloud.google.com öffnen → neues Projekt anlegen (z.B. „CAO-XT Habacher Dorfladen").
  2. „APIs & Services" → „Library" → Gmail API aktivieren.
  3. „OAuth consent screen" → User type Internal → App-Name + Support-E-Mail eintragen → Speichern.
  4. „Credentials" → „Create Credentials" → „OAuth client ID" → Application type Web application.
  5. Authorized redirect URI eintragen (genau diese URL):
    …
  6. Client ID + Client Secret unten eintragen → Speichern.
  7. „🔗 Mit Google verbinden" klicken → Consent → fertig.
